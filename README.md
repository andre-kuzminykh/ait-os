# AI Business Operating System (AI BOS)

Workspace OS — единая среда работы человека и ИИ на Streamlit.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура интерфейса

| Зона | Описание |
|------|----------|
| **Левая панель** | Дерево рабочего пространства — проекты, документы, файлы |
| **Центр** | Редактор / просмотр выбранного объекта |
| **Правая панель** | Контекстный AI-чат |
| **Нижняя панель** | Лента задач и их статус |
